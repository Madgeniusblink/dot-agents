# Personal and overlay skills

Skills here are **not** part of the three-skill template budget under `home/skills/`
(see [decision 0008](https://github.com/Madgeniusblink/dot-agents/blob/main/docs/decisions/0008-ship-no-fill-in-files.md)).

Install into your home overlay:

```sh
cp -R contrib/skills/cris-mode ~/.agents/skills/
```

After copy, run `agents check` from `~/.agents`.
