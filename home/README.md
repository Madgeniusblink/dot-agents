# Agent home

This directory is the agent home. A checkout of it is `~/.agents`. The router is [AGENTS.md](AGENTS.md); [docs/setup.md](docs/setup.md) points a tool at it, and [standards/adopt.md](standards/adopt.md) says how to take the template's changes.

It comes from the dot-agents template: <https://github.com/Madgeniusblink/dot-agents>. The template's root holds the `agents` binary's source and the maintainer files, which a home does not carry.
