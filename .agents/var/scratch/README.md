# Scratch

Ephemeral agent output: drafts, pasted logs, scratchpad notes, one-off scripts.

- Do **not** commit contents of this directory.
- Delete old files anytime.
- Subfolders by repo or date are fine (`my-app/`, `2026-11-01/`).

Default: `~/.agents/var/scratch/` (override with `DOT_AGENTS_SCRATCH`).
