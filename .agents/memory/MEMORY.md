# Memory

One fact per file. Agents list this folder and open files by name and title,
so a new file needs no entry here.

Use this file only for notes that apply to all memory. Review monthly; delete
stale files.

Optional personal file: `voice.md` (how the user wants status and decisions
reported). The [report](../skills/report/SKILL.md) skill loads it only when
reporting, not every turn. Keep it short.
