# Style guide

## Prose (required)

All text in this tree must follow [ASD-STE100](writing-standard.md). Use the official dictionary at [asd-ste100.org](https://www.asd-ste100.org/) for disputed word choice.

## Code

- Match the owning repo. If the repo has no style, use a small diff and match nearby code.
- TypeScript: see [rules/typescript.md](../rules/typescript.md).

## Files

- One idea per file.
- Lead with the outcome in the first line when the file is normative.
