# Writing standard (ASD-STE100)

All new text in this tree **must** follow **ASD-STE100** (Simplified Technical English).

## Authority

- Spec and dictionary: [asd-ste100.org](https://www.asd-ste100.org/)
- Issue STE100 dictionary for serious work; the site describes the standard.

We do not duplicate the dictionary here. We apply its rules in this tree.

Use **must** for requirements. Use **can** for permission. Do not use vague "should" in normative files.

## Scope

Applies to: [standards/](../standards/), [rules/](../rules/), [skills/](../skills/), [checklists/](../checklists/), and [context/](.) files.

Code comments in this tree should follow the same rules when you add them.

## Code style

STE100 applies to **prose**, not to code syntax. Code matches the owning repo.
