# Writing standard (ASD-STE100)

All new text in this tree **must** follow **ASD-STE100** (Simplified Technical English).

## Authority

- Spec and dictionary: [asd-ste100.org](https://www.asd-ste100.org/)
- Issue STE100 dictionary for serious work; the site describes the standard.

We do not duplicate the dictionary here. We apply its rules in this tree.

## Rules (summary)

1. Use **approved** words when the dictionary gives a choice.
2. Write **short** sentences. One idea per sentence.
3. Use **active** voice. Name the actor.
4. Do not use slang or jargon without a [glossary](glossary.md) entry.
5. Use **must** for requirements. Use **can** for permission. Do not use vague "should" in normative files.

## Scope

Applies to: [standards/](../standards/), [rules/](../rules/), [skills/](../skills/), [checklists/](../checklists/), [workflows/](../workflows/), [schedules/](../schedules/), [templates/](../templates/), and [context/](.) files.

Code comments in this tree should follow the same rules when you add them.

## Code style

For programming style, see [style-guide.md](style-guide.md). STE100 applies to **prose**, not to code syntax.
