# Glossary

Add terms and acronyms you use across repos. One term per bullet.

- **Context** — Personal agent canon installed from `Madgeniusblink/context` (separate from this folder when runtime occupies the same path).
- **dot-agents** — Public template repo for project `.agents/` trees.
- **Upstream** — Canonical template source ([upstream.json](context/upstream.json)); use `dot-agents upstream` for links.
- **Overlay** — Your files beside upstream (extra skills, memory, scratch); kept on default install.
- **Extend** — Add artifacts per [standards/](../standards/); change shared template via PR on upstream.
- **Scratch** — Ephemeral agent files under `var/scratch/` (not committed).
- **Worktrees** — Agent git worktrees under `var/worktrees/` (not committed).
