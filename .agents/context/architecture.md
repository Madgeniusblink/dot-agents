# Architecture (personal)

Describe how your machines, repos, and runtimes connect. Update when layout changes.

- **Template source:** `.agents/` tree and [standards/](../standards/) from the repo named in [upstream.json](upstream.json).
- **Global home:** `~/.agents/` — [install.sh](../../install.sh) or [standards/install.md](../standards/install.md).
- **Git clones:** edit the template in your clone; re-run install to refresh upstream-owned files.

Optional scratch and worktree dirs: [optional-extensions.md](optional-extensions.md).
