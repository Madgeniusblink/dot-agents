# Plan → build → review

1. **Plan** — Confirm scope; read [decisions/](../decisions/) and relevant [rules/](../rules/).
2. **Build** — Smallest correct diff; use [profiles/fast-prototype.md](../profiles/fast-prototype.md) or strict mode as chosen.
3. **Review** — [skills/self-verify](../skills/self-verify/SKILL.md); [checklists/before-commit.md](../checklists/before-commit.md).
4. **Handoff** — Drop a file in [handoffs/](../handoffs/) if the session stops mid-work.
