# Standards index

Public contract for extending `~/.agents/` or `<repo>/.agents/`.

**Writing:** All standards and new files must follow [ASD-STE100](../context/writing-standard.md).

**Sources:** Link to live docs first. See [sources-policy](../context/sources-policy.md).

| Artifact | Standard file | Primary live reference |
|----------|---------------|------------------------|
| Skills | [skills.md](skills.md) | [Cursor Skills docs](https://cursor.com/docs/skills) |
| Rules | [rules.md](rules.md) | [Cursor Rules docs](https://cursor.com/docs/context/rules) |
| Schedules | [schedules.md](schedules.md) | (local format; link cron/launchd docs) |
| Decisions | [decisions.md](decisions.md) | [ADR](https://adr.github.io/) |
| Checklists | [checklists.md](checklists.md) | Local; STE100 only |
| Workflows | [workflows.md](workflows.md) | Local; link steps to skills |
| Evals | [evals.md](evals.md) | Local; pair with [agents.md](https://agents.md/) entry pattern |
| Templates | [templates.md](templates.md) | Link ADR/spec URLs before local stub |
| Install | [install.md](install.md) | `dot-agents` CLI in repo root |

When someone asks "what is the template standard?", send them **this folder** and [foundation.md](../context/foundation.md).
