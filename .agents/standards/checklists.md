# Standard: checklists

No global URL. Checklists are local **done criteria**.

Path: `.agents/checklists/<name>.md`

Format:

- Title
- Markdown task list (`- [ ]`)
- Each item is one verifiable action

Rules:

1. STE100 ([writing-standard](../context/writing-standard.md)).
2. Link from [AGENTS.md](../AGENTS.md) or [self-verify](../skills/self-verify/SKILL.md).
3. Examples: [before-commit.md](../checklists/before-commit.md), [before-release.md](../checklists/before-release.md).
