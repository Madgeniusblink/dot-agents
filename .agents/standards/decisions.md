# Standard: decisions

## Live reference (read first)

- [Architecture Decision Records](https://adr.github.io/)

Use the ADR format from that site. Local file name:

`.agents/decisions/NNNN-<short-title>.md`

## Rules

1. Record **settled** choices only. Open questions belong in a spec or issue.
2. STE100 ([writing-standard](../context/writing-standard.md)).
3. Link related [rules/](../rules/) when a decision becomes a scoped rule.
