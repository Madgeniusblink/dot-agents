# Standard: workflows

A workflow is a **ordered list of links**, not a copy of vendor docs.

Path: `.agents/workflows/<name>.md`

1. Name the pipeline in the title.
2. Number steps. Each step links to a skill, checklist, or profile.
3. STE100 ([writing-standard](../context/writing-standard.md)).

Example: [plan-build-review.md](../workflows/plan-build-review.md).
