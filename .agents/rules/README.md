# Scoped rules (optional)

Add a file here when you need rules that apply only to some paths.

Some tools support optional YAML front matter with `globs:` — see [standards/adapters.md](../standards/adapters.md).

See [standards/rules.md](../standards/rules.md).

Do not add a rule file until you have a real topic. Language-specific examples belong in **your** fork, not the global base template.
