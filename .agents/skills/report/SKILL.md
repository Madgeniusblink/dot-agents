# Report

Apply the user's reporting preferences before the reply leaves chat.

## Workflow

1. If [memory/voice.md](../../memory/voice.md) exists, read **How to report to me**
   and follow it for this message only.
2. Otherwise use [principles.md](../../principles.md) and
   [rules/corrections.md](../../rules/corrections.md) for tone and decisions.
3. Lead with the outcome or next action. Keep the body to what the user asked
   for. One closing line if something obvious remains.

Do not load other memory files for a routine status update.
